    읽는 방법

    • 난이도: ★(1~5개)로 표시합니다. 바이브 코딩(Claude Code 중심 개발) 기준입니다.
      • ★ : 단일 HTML 파일(순수 JS)로 반나절~하루 안에 가능
      • ★★ : 단일 페이지 앱 + 로컬 저장(localStorage/IndexedDB), 1~3일
      • ★★★ : 외부 라이브러리·API 연동 또는 비교적 복잡한 로직, 3~7일
      • ★★★★ : 서버/DB, 모델 추론, 복잡한 계산 엔진이 필요, 1~3주
      • ★★★★★ : 연구 수준의 알고리즘이나 대규모 데이터 처리가 필요, 3주 이상
    • 형태: 웹(단일 HTML) / 웹(Streamlit 등 파이썬) / PWA(모바일 설치형) / 데스크톱 스크립트
    • 외부 API는 정책·요금·약관이 바뀔 수 있으므로 구현 전에 최신 내용을 꼭 확인해 주십시오.
    • 이 문서는 제 지식을 바탕으로 정리한 것이며, 실시간 웹 조사를 거친 것은 아닙니다.

    1. 통계 및 데이터분석

    강점: 파이썬·Pandas·Orange3 경험이 있으시므로 Streamlit, Dash, Pyodide(브라우저에서 파이썬 실행) 등을 활용하면 좋습니다.

    1-1. 회귀분석 결과 해석 도우미

    • 목표: statsmodels 등에서 나온 회귀분석 결과 표를 붙여 넣으면 APA 형식 표와 해석 문장을 자동으로 만들어 줍니다.
    • 핵심 기능
      • 결과 텍스트(summary) 붙여넣기 → 계수·표준오차·p값·R² 자동 파싱
      • APA 7판 형식 표 및 한글/영문 해석 문장 생성
      • 가정 점검 체크리스트(잔차 정규성, 등분산성, 다중공선성 VIF) 안내
      • Word/Markdown 복사 기능
    • 기술: Streamlit + statsmodels, 또는 순수 JS 파서
    • 난이도: ★★★ (결과 형식 파싱이 까다롭습니다. CSV 업로드 후 앱에서 직접 분석하게 하면 ★★)
    • 확장: 위계적 회귀, 조절·매개효과(PROCESS 방식) 해석 템플릿 추가

    1-2. 구조방정식모형(SEM) 경로도 그리기 & 적합도 해석기

    • 목표: 잠재변수·측정변수·경로를 그려서 모형을 만들고, 적합도 지수(CFI, TLI, RMSEA, SRMR)의 기준 충족 여부를 알려 줍니다.
    • 핵심 기능
      • 드래그 앤 드롭 경로도 편집기 → lavaan/semopy 문법 자동 생성
      • 적합도 지수 입력 시 기준(Hu & Bentler) 대비 신호등 표시
      • 표준화 계수를 경로도 위에 표시한 SVG/PNG 내보내기
      • 모형 식별(자유도) 자동 계산
    • 기술: JS(SVG 캔버스) + 선택적으로 semopy(Python)
    • 난이도: ★★★★ (경로도 편집기 UI가 핵심입니다. 문법 생성만 하면 ★★★)

    1-3. 통계 개념 시각화 실험실

    • 목표: 슬라이더를 움직이며 통계 개념을 직관적으로 이해합니다. 수업·연수 자료로도 활용할 수 있습니다.
    • 핵심 기능
      • 중심극한정리, 신뢰구간 커버리지, p값과 검정력, 1·2종 오류 시뮬레이션
      • 상관계수와 산점도, 이상치 한 점의 영향력, 심프슨의 역설
      • 다층모형: 집단별 회귀선과 전체 회귀선의 차이 시각화
      • 시뮬레이션 반복 횟수·표본 크기 조절
    • 기술: 단일 HTML + Canvas/Chart.js (또는 D3)
    • 난이도: ★★ (모듈별로 나눠 하나씩 추가하면 됩니다.)
    • 포인트: 초등 교사용 도구 개발 경험과 가장 잘 이어지는 아이디어입니다.

    1-4. 다층모형(HLM) 시나리오 시뮬레이터 & ICC 계산기

    • 목표: 집단 수, 집단 크기, ICC에 따라 추정 정밀도와 검정력이 어떻게 달라지는지 확인합니다.
    • 핵심 기능
      • ICC·설계효과(design effect) 계산
      • 표본 구성(집단 수 × 집단 내 인원)별 검정력 곡선
      • 무선절편/무선기울기 데이터 생성 및 CSV 다운로드
      • 모형 선택 가이드(영모형 → 무선절편 → 무선기울기)
    • 기술: Streamlit + statsmodels(mixedlm) 또는 Pyodide
    • 난이도: ★★★
    • 활용: 연구 설계 단계에서 표본 크기를 정당화할 때 유용합니다.

    1-5. 통계 분석 방법 선택 마법사

    • 목표: 변수 유형과 연구 질문을 고르면 적합한 분석 방법과 가정 점검 사항, 파이썬 코드 스니펫을 알려 줍니다.
    • 핵심 기능
      • 질문 흐름도(종속변수 척도, 독립변수 수, 집단 수, 대응 여부 등)
      • 추천 분석 + 대안(비모수) + 효과크기 지표
      • 파이썬(scipy/statsmodels/pingouin) 코드 템플릿 복사
      • 보고서 문장 예시
    • 기술: 단일 HTML (결정 트리 JSON)
    • 난이도: ★★ (내용 설계가 핵심이며 코드는 쉽습니다.)

    1-6. 논문 통계표 → 데이터 복원/재현 검증기

    • 목표: 논문에 보고된 평균·표준편차·표본 수로 t값, 효과크기, p값을 재계산하여 보고 오류를 점검합니다. (GRIM/statcheck 개념)
    • 핵심 기능
      • 평균·SD·N 입력 → t검정, Cohen's d, 신뢰구간 재계산
      • 보고된 p값과 불일치 여부 표시
      • 정수형 척도 평균의 불가능한 값 탐지(GRIM 테스트)
      • 메타분석용 효과크기 변환(d ↔ r ↔ OR)
    • 기술: 단일 HTML + jStat, 또는 Streamlit
    • 난이도: ★★
    • 활용: 선행연구 검토와 메타분석 준비에 좋습니다.

    1-7. 설문 데이터 클리닝 & 신뢰도·타당도 리포트 자동 생성기

    • 목표: 설문 CSV/Excel을 올리면 결측·이상응답을 점검하고 신뢰도(Cronbach's α, McDonald's ω)와 탐색적 요인분석 결과를 한 번에 리포트로 만듭니다.
    • 핵심 기능
      • 불성실 응답 탐지(동일 응답 패턴, 응답 시간)
      • 역코딩 문항 지정, 하위 요인별 점수 산출
      • α/ω, 문항-총점 상관, 문항 삭제 시 α 변화
      • 기술통계 표, 정규성 검정, 히스토그램, PDF/HTML 리포트
    • 기술: Streamlit + pandas + pingouin/factor_analyzer
    • 난이도: ★★★
    • 포인트: 반복 작업을 가장 많이 줄여 주는 실무형 도구입니다.

    1-8. 코딩북(Codebook) & 변수 사전 관리자

    • 목표: 데이터 파일의 변수 이름, 라벨, 값 라벨, 척도, 결측 코드를 한곳에서 관리하고 분석 코드에 자동 반영합니다.
    • 핵심 기능
      • CSV 업로드 시 변수 자동 탐지 및 라벨 편집
      • 값 라벨 매핑(1=매우 그렇지 않다 …)을 pandas 변환 코드로 내보내기
      • 변수 그룹(척도별 문항) 관리와 역코딩 표시
      • 코드북 PDF/Markdown 출력
    • 기술: Streamlit 또는 단일 HTML + SheetJS
    • 난이도: ★★
    • 활용: 장기 연구·학위 논문 데이터 관리에 유용합니다.

    1-9. Orange3 스타일 노코드 분석 워크플로 웹 앱

    • 목표: 브라우저에서 위젯을 연결하는 방식으로 데이터 불러오기 → 변환 → 시각화 → 모형 적합을 해 볼 수 있는 가벼운 교육용 도구를 만듭니다.
    • 핵심 기능
      • 노드 기반 캔버스(파일, 필터, 기술통계, 산점도, 회귀)
      • 각 노드의 결과를 표와 차트로 미리보기
      • 워크플로 저장/불러오기(JSON)
      • 노드에서 파이썬 코드 생성
    • 기술: JS(노드 에디터, Pyodide 연동)
    • 난이도: ★★★★★ (범위를 줄여 노드 4~5종만 만들면 ★★★★)
    • 포인트: 도전적이지만 학생 교육용으로 가치가 큽니다.

    1-10. 공공데이터 탐색 & 스토리텔링 대시보드

    • 목표: KOSIS, 공공데이터포털, 교육통계서비스(KESS) 등의 데이터를 불러와 시각화하고 해석 문장을 붙여 보고서 형태로 저장합니다.
    • 핵심 기능
      • 데이터 소스 프리셋 + CSV 업로드
      • 추세·상관·지역별 비교 차트 자동 추천
      • 이상치·구조 변화 시점 표시
      • 차트별 코멘트 작성 → 한 장짜리 리포트 내보내기
    • 기술: Streamlit/Dash + Plotly
    • 난이도: ★★★ (API 인증키 관리와 데이터 정제가 번거롭습니다.)

    2. 사진 촬영 및 편집

    2-1. 사진 메타데이터(EXIF) 분석 대시보드

    • 목표: 촬영한 사진의 EXIF를 분석하여 나의 촬영 습관(자주 쓰는 화각, 조리개, ISO, 셔터 속도, 시간대)을 데이터로 보여 줍니다.
    • 핵심 기능
      • 폴더 단위 사진 업로드 → EXIF 일괄 추출(브라우저에서 처리하면 업로드 불필요)
      • 초점거리 분포, 조리개·ISO 히스토그램, 시간대별 촬영량
      • 렌즈별 사용 비율 → "이 초점거리 렌즈는 필요 없다/필요하다" 판단 근거
      • 월별 촬영 캘린더 히트맵
    • 기술: 단일 HTML + exifr 라이브러리 (또는 Python + Pandas)
    • 난이도: ★★
    • 포인트: 데이터 분석 실력과 사진 취미를 가장 자연스럽게 결합합니다.

    2-2. 촬영 계획 도우미 (골든아워·일출몰·달 위상)

    • 목표: 촬영 날짜와 장소를 입력하면 일출·일몰, 골든아워·블루아워, 달의 위상, 은하수 가시 시간을 계산해 줍니다.
    • 핵심 기능
      • 위치(지도 클릭 또는 좌표) 기준 태양·달 정보 계산
      • 해가 지는 방향을 지도 위에 선으로 표시
      • 촬영 체크리스트(장비, 배터리, 삼각대)와 날씨 연동
      • 여행 일정과 연동한 촬영 포인트 저장
    • 기술: SunCalc.js + Leaflet + 날씨 API
    • 난이도: ★★★
    • 확장: 5번 여행 항목의 일정 앱과 합칠 수 있습니다.

    2-3. 사진 일괄 정리·이름 변경 도구

    • 목표: 촬영 일시·카메라·장소를 기준으로 사진 파일을 자동 분류하고 이름을 규칙에 맞게 바꿉니다.
    • 핵심 기능
      • YYYY-MM-DD_장소_번호 같은 규칙 템플릿
      • 폴더 구조 자동 생성(연/월/이벤트), 중복 파일 탐지(해시)
      • RAW+JPG 쌍 처리, 미리보기 후 실행(되돌리기 로그 필수)
      • 위치 정보로 도시 이름 자동 변환
    • 기술: Python(PySimpleGUI/Tkinter 또는 CLI) + Pillow/exifread
    • 난이도: ★★★ (파일을 직접 옮기므로 안전장치가 중요합니다.)

    2-4. 사진 선별(컬링) 보조 앱

    • 목표: 비슷한 사진 수백 장 중에서 가장 좋은 컷을 빠르게 고릅니다.
    • 핵심 기능
      • 연속 촬영 사진 자동 그룹화(시간·유사도)
      • 선명도(라플라시안 분산), 노출 과다·부족 점수 표시
      • 키보드 단축키로 별점·픽·리젝 후 결과를 XMP/CSV로 내보내기
      • 두 장 비교 확대 보기(100% 크롭 동기화)
    • 기술: Python + OpenCV, 또는 웹(Canvas)
    • 난이도: ★★★★ (대용량 이미지 처리 성능과 UX가 관건입니다.)

    2-5. 구도 연습 & 사진 분석 코치

    • 목표: 내 사진에 삼등분선·황금비·대각선 가이드를 겹쳐 보고, 구도를 스스로 점검합니다.
    • 핵심 기능
      • 구도 오버레이(삼분할, 황금나선, 대칭, 소실점)
      • 크롭 시뮬레이터(비율 1:1, 4:5, 16:9 등)
      • 색상 팔레트 추출, 밝기 히스토그램, 주 피사체 위치 점수
      • "오늘의 촬영 미션" 카드(예: 선 활용하기)
    • 기술: 단일 HTML + Canvas
    • 난이도: ★★ (AI 코멘트를 붙이면 Claude API 연동으로 ★★★)

    2-6. 보정(프리셋) 레시피 저장소 & 비교 앱

    • 목표: 나만의 보정 값을 기록하고 전후를 비교하며, 상황별 최적 설정을 축적합니다.
    • 핵심 기능
      • 슬라이더(노출, 대비, 채도, 색온도, 비네팅)를 적용한 실시간 미리보기
      • 프리셋 저장·공유(JSON), 전후 비교 슬라이더
      • 상황 태그(야경, 인물, 풍경)별 라이브러리
      • 라이트룸 프리셋 값 메모 필드
    • 기술: 단일 HTML + Canvas/WebGL 필터
    • 난이도: ★★★
    • 참고: 라이트룸 파일(XMP) 호환은 범위가 커서 처음엔 제외하는 것이 좋습니다.

    2-7. 사진 전시/포트폴리오 갤러리 생성기

    • 목표: 폴더의 사진과 설명 텍스트로 정적 웹 갤러리를 자동 생성하여 깃허브 페이지 등에 올립니다.
    • 핵심 기능
      • 썸네일·반응형 이미지 자동 생성, 촬영 정보 자동 표시
      • 컬렉션(여행별, 주제별) 구성, 지도 보기
      • 라이트박스, 키보드 탐색, 다크 모드
      • EXIF 개인정보(GPS) 제거 옵션
    • 기술: Python 스크립트 + 정적 HTML 템플릿
    • 난이도: ★★★

    2-8. 사진 촬영 일지 & 장비 관리

    • 목표: 촬영 기록, 장비 사용 횟수(셔터 수), 구매·중고 가치, 장비 위시리스트를 관리합니다.
    • 핵심 기능
      • 장비 목록(바디, 렌즈, 필터)과 구매가·구매일
      • 촬영 일지(장소, 사용 장비, 느낀 점, 대표 사진)
      • 촬영당 장비 비용, 사용 빈도 분석
      • 가방 패킹 리스트
    • 기술: PWA + IndexedDB
    • 난이도: ★★

    2-9. 노출 삼각형 학습 & 시뮬레이터

    • 목표: 조리개·셔터·ISO를 조작하며 사진이 어떻게 달라지는지 체험합니다. 입문자(가족·지인·학생)에게 설명할 때도 유용합니다.
    • 핵심 기능
      • 조리개 → 배경 흐림, 셔터 → 움직임 흐림, ISO → 노이즈를 시각적으로 시뮬레이션
      • 노출 값(EV) 계산과 등가 노출 조합 표
      • 피사계 심도, 과초점 거리 계산기
      • 퀴즈 모드("이 사진의 설정은?")
    • 기술: 단일 HTML + Canvas/CSS blur
    • 난이도: ★★
    • 포인트: 교수학습 도구 개발 경험을 그대로 활용할 수 있습니다.

    2-10. 사진 스타일 분석 & 유사 사진 찾기

    • 목표: 내가 찍은 사진들의 색감·밝기·구도 경향을 정량화하고, "내 스타일"을 시각화합니다.
    • 핵심 기능
      • 사진별 색상 특징(평균 색상, 채도, 명도)을 벡터화하여 군집 분석
      • 2차원 지도에 사진을 배치(t-SNE/UMAP)
      • 시기별 스타일 변화 추적
      • 비슷한 사진 묶기와 중복 후보 탐지
    • 기술: Python + scikit-learn + 사전학습 모델(CLIP 등), Streamlit
    • 난이도: ★★★★
    • 포인트: 머신러닝 요소를 가장 많이 실험할 수 있습니다.

    3. 언어 공부 (영어·일본어·스페인어)

    3-1. 동사 활용형 연습기 (일본어·스페인어)

    • 목표: 일본어 동사·형용사 활용과 스페인어 동사 활용(직설법·접속법 등)을 규칙 기반으로 무한 생성해 연습합니다.
    • 핵심 기능
      • 활용 규칙 엔진(1·2·3그룹, 불규칙 동사 사전)
      • 시제·법·인칭 선택 후 문제 출제, 즉시 채점
      • 오답 노트와 간격 반복(SRS) 복습
      • 활용표 보기 및 규칙 설명
    • 기술: 단일 HTML (규칙 JSON)
    • 난이도: ★★★ (스페인어 불규칙 동사 데이터 입력이 가장 큰 작업입니다.)

    3-2. 다국어 단어장 + 간격 반복 학습 (SRS)

    • 목표: 영어·일본어·스페인어 단어를 한 앱에서 관리하며 망각곡선에 맞춰 복습합니다.
    • 핵심 기능
      • 언어별 카드 덱, 예문·발음 메모, 태그
      • SM-2 또는 FSRS 알고리즘, 오늘의 복습 목록
      • 책이나 기사에서 만난 단어를 빠르게 추가하는 입력 폼
      • 학습 통계(정답률, 연속 학습일)와 CSV 가져오기/내보내기(Anki 호환)
    • 기술: PWA + IndexedDB
    • 난이도: ★★★
    • 참고: 기존 Anki와 차별화하려면 3-5, 3-9와 같은 맥락 기능을 붙이는 것이 좋습니다.

    3-3. 영어 쉐도잉 & 발음 피드백

    • 목표: 영어 문장을 듣고 따라 말하면 음성 인식 결과와 원문을 비교해 알려 줍니다.
    • 핵심 기능
      • 문장 재생(브라우저 TTS), 속도 조절, 구간 반복
      • 음성 인식(Web Speech API) 결과와 원문 비교(단어 단위 diff 색상 표시)
      • 정확도 점수와 약한 발음(예: r/l, th) 통계
      • 오늘의 문장 추천
    • 기술: 단일 HTML + Web Speech API (크롬 기준)
    • 난이도: ★★ (브라우저 지원 범위와 인식 정확도 한계를 감안해야 합니다.)

    3-4. 일본어 한자 & 읽기(후리가나) 학습기

    • 목표: 일본어 글을 붙여 넣으면 후리가나와 단어 뜻을 보여 주고, 모르는 한자를 단어장에 추가합니다.
    • 핵심 기능
      • 형태소 분석으로 후리가나 자동 표시(토글)
      • 단어 클릭 시 한국어/영어 뜻, JLPT 급수 표시
      • 한자별 획순·음독·훈독 카드와 JLPT 레벨별 필터
      • 읽기 속도 기록
    • 기술: 브라우저용 형태소 분석기(kuromoji.js) + JMdict 사전 데이터
    • 난이도: ★★★★ (사전 데이터 가공과 용량 관리가 필요합니다.)

    3-5. 책·기사 기반 어휘 추출기

    • 목표: 읽고 있는 텍스트(영어 기사, 스페인어 뉴스 등)에서 학습 가치가 높은 어휘를 뽑아 단어장으로 보냅니다.
    • 핵심 기능
      • 텍스트 붙여넣기 → 단어 빈도·난이도 분석
      • 이미 아는 단어 제외(내 단어장과 비교)
      • 텍스트 커버리지(이 글의 몇 %를 이해하는가) 계산
      • 문맥 문장과 함께 카드 생성
    • 기술: 단일 HTML 또는 Python(spaCy/NLTK)
    • 난이도: ★★★
    • 포인트: 텍스트 마이닝 경험을 활용할 수 있습니다.

    3-6. 언어 학습 시간·성취 기록 대시보드

    • 목표: 세 언어의 학습 시간과 성취를 기록하고 데이터로 동기를 유지합니다.
    • 핵심 기능
      • 타이머 + 학습 유형(듣기, 읽기, 말하기, 쓰기) 기록
      • 주·월별 학습량 차트, 연속 학습일(streak)
      • 목표(예: JLPT N3, DELE A2)까지 필요 시간 추정
      • 나의 최적 학습 시간대 분석
    • 기술: PWA + Chart.js
    • 난이도: ★★

    3-7. AI 회화 파트너 (롤플레이 상황극)

    • 목표: 상황(공항, 식당, 호텔)을 고르면 Claude가 외국어로 대화를 이어 주고, 수준에 맞춰 교정해 줍니다.
    • 핵심 기능
      • 상황·난이도·언어 선택, 대화 중 부담 없는 힌트
      • 문장별 교정과 더 자연스러운 표현 제안
      • 대화 후 요약: 새로 쓴 표현, 오류 유형 통계
      • 여행 전 "현지 상황 대비" 모드(5번 항목과 연결)
    • 기술: Claude API + 간단한 웹 UI (키 관리를 위해 서버 프록시 권장)
    • 난이도: ★★★ (API 키 보안과 비용 관리가 핵심입니다.)

    3-8. 문법 패턴 카드 & 예문 뱅크

    • 목표: 문법 패턴(예: 일본어 ～ている, 스페인어 ser/estar)을 예문 중심으로 정리하고 테스트합니다.
    • 핵심 기능
      • 패턴별 설명(간단), 예문 5~10개, 비교 카드(유사 표현)
      • 빈칸 채우기·문장 배열 문제
      • 내가 틀린 패턴 자동 재출제
      • 직접 만난 예문 저장
    • 기술: 단일 HTML
    • 난이도: ★★ (콘텐츠 제작이 핵심이며, Claude로 초안을 만들고 검수하는 방식이 효율적입니다.)

    3-9. 여행 필수 회화 플래시 카드 (오프라인)

    • 목표: 여행지에서 바로 쓸 수 있는 표현을 상황별로 모은 오프라인 회화집입니다.
    • 핵심 기능
      • 상황 분류(식당, 교통, 숙소, 응급), 한국어-원어-발음 병기
      • 음성 재생(TTS), 즐겨찾기
      • 큰 글씨로 상대에게 보여 주기 모드
      • 가격·숫자 읽기 연습
    • 기술: PWA(오프라인 캐시)
    • 난이도: ★★

    3-10. 언어 간 비교 학습 노트 (영·일·스)

    • 목표: 같은 의미를 세 언어로 나란히 정리하여 언어 간 공통점과 차이를 이해합니다.
    • 핵심 기능
      • 한 개념(인사, 시간, 부정, 의문)을 3개 언어로 비교하는 표
      • 어순·품사·시제 비교 시각화
      • 같은 어원/외래어 찾기(예: 영어-스페인어 동족어)
      • 비교 퀴즈
    • 기술: 단일 HTML
    • 난이도: ★★
    • 포인트: 여러 언어를 동시에 공부하는 사람에게 차별화된 도구입니다.

    4. 독서·음악 감상

    4-1. 독서 기록 & 인용문 수집기

    • 목표: 읽은 책, 진행률, 인상 깊은 문장과 생각을 한곳에 모읍니다.
    • 핵심 기능
      • 책 정보 자동 입력(ISBN/제목 검색, 도서 API)
      • 읽는 중·읽은 책·읽고 싶은 책 상태 관리, 별점
      • 인용문(쪽수 포함)과 메모 저장, 태그·검색
      • 연간 독서량 통계와 독서 캘린더
    • 기술: PWA + IndexedDB, 도서 검색 API
    • 난이도: ★★★ (API 연동 없이 수동 입력만 하면 ★★)

    4-2. 독서 통계 & 취향 분석

    • 목표: 독서 기록 데이터로 나의 독서 패턴(장르, 저자 국적, 분량, 월별 추이)을 분석합니다.
    • 핵심 기능
      • CSV(굿리즈, 알라딘 내보내기 등) 가져오기
      • 장르 비중, 출판 연도 분포, 책 길이와 완독 속도
      • "올해의 독서 리포트" 이미지 카드 생성
      • 독서 목표 달성 예측
    • 기술: Streamlit + Pandas + Plotly
    • 난이도: ★★
    • 포인트: 개인 데이터 분석 프로젝트로 시작하기 좋습니다.

    4-3. 책 속 문장 → 지식 연결 노트 (제텔카스텐식)

    • 목표: 인용문과 생각을 서로 연결하여 나만의 지식 네트워크를 만듭니다.
    • 핵심 기능
      • 노트 간 링크([[노트]])와 역링크
      • 그래프 뷰로 개념 연결 시각화
      • 태그·주제별 모아 보기, 무작위 노트 복습
      • Markdown 내보내기(옵시디언 호환)
    • 기술: 단일 HTML + D3/vis-network
    • 난이도: ★★★

    4-4. 음악 청취 기록 분석 (Last.fm/Spotify 데이터)

    • 목표: 내 청취 이력으로 나의 음악 취향 변화를 분석합니다.
    • 핵심 기능
      • Spotify 데이터 내보내기 파일이나 Last.fm API로 이력 불러오기
      • 아티스트·장르·시간대별 청취 패턴, 가장 많이 들은 곡
      • 연도별 취향 변화, 새 음악 vs 반복 청취 비율
      • 요약 카드(공유용 이미지)
    • 기술: Streamlit + Pandas
    • 난이도: ★★★
    • 포인트: 데이터 분석 실습과 음악 취미를 결합합니다.

    4-5. 음악 감상 일지 & 앨범 리뷰 아카이브

    • 목표: 들은 앨범에 대한 감상을 짧게 기록하고 평점·태그를 관리합니다.
    • 핵심 기능
      • 앨범/곡 검색 및 자동 정보 입력(MusicBrainz API)
      • 평점, 감상 메모, 감상 날짜·장소·기분 태그
      • "그때 들었던 음악" 타임라인
      • 연말 베스트 앨범 목록 자동 생성
    • 기술: PWA + IndexedDB
    • 난이도: ★★★

    4-6. 음악 이론 학습 도구 (코드·스케일·음정)

    • 목표: 악기를 연주하거나 음악 이론을 공부할 때 쓰는 인터랙티브 도구입니다.
    • 핵심 기능
      • 스케일/코드 구성음 표시, 피아노/기타 지판 시각화
      • 코드 진행 재생(Web Audio API)
      • 청음 훈련(음정·코드 맞히기)
      • 키 변환(트랜스포즈) 계산기
    • 기술: 단일 HTML + Web Audio API 또는 Tone.js
    • 난이도: ★★★
    • 포인트: 교육용 도구 제작 경험이 가장 잘 이어집니다.

    4-7. 플레이리스트 분위기 분석 & 상황별 큐레이터

    • 목표: 곡 목록을 올리면 분위기(에너지, 템포, 밝기)를 분석하고 상황(공부, 운동, 드라이브)에 맞게 정렬·추천합니다.
    • 핵심 기능
      • 곡 메타데이터에서 BPM·키·에너지 지표 활용(오디오 분석 라이브러리 또는 API)
      • 분위기 맵(2차원 산점도)에서 곡 클러스터링
      • 곡 간 부드러운 전환 순서 추천(BPM·키 근접도)
      • 상황별 플레이리스트 저장
    • 기술: Python(librosa) + Streamlit
    • 난이도: ★★★★ (Spotify 오디오 특성 API는 접근 정책이 달라질 수 있어 librosa로 직접 분석하는 방식을 권장합니다.)

    4-8. 독후감 & 서평 쓰기 코치

    • 목표: 읽은 책에 대한 생각을 구조화하여 독후감을 쓰도록 돕습니다.
    • 핵심 기능
      • 질문 가이드(핵심 주장, 인상 깊은 부분, 나의 반론, 적용점)
      • 메모와 인용문을 모아 초안 자동 구성
      • Claude의 피드백(논리 흐름, 표현) 선택 기능
      • 글자 수·소요 시간 기록
    • 기술: Claude API + 단일 HTML
    • 난이도: ★★★

    4-9. 독서 모임/함께 읽기 진도 관리

    • 목표: 친구·동료와 같은 책을 함께 읽으며 진도와 토론 질문을 공유합니다.
    • 핵심 기능
      • 모임 책 설정, 주차별 읽기 범위, 개인 진도 체크
      • 토론 질문 등록 및 투표, 한 줄 감상 공유
      • 출석·진도 현황 대시보드
      • 모임 일정 알림(캘린더 내보내기)
    • 기술: Firebase/Supabase 등 백엔드 + 웹 앱
    • 난이도: ★★★★ (여러 사용자 간 동기화가 필요합니다.)

    4-10. 클래식·재즈 입문 가이드북 (작곡가·시대·감상 포인트)

    • 목표: 클래식·재즈를 체계적으로 감상하기 위한 지도를 제공합니다.
    • 핵심 기능
      • 시대별 타임라인, 작곡가·연주자 관계도
      • 곡별 감상 포인트와 추천 연주(유튜브 링크 저장)
      • "들어 봤어요/좋았어요" 체크리스트와 진행률
      • 난이도별 감상 코스(입문→심화)
    • 기술: 단일 HTML (콘텐츠 JSON)
    • 난이도: ★★ (콘텐츠 정확성 검수가 중요합니다.)

    5. 여행

    5-1. 여행 일정 타임라인 플래너

    • 목표: 날짜·시간별로 일정을 짜고 이동 시간을 확인하며, 일정을 한눈에 보는 계획 도구입니다.
    • 핵심 기능
      • 일자별 타임라인, 드래그로 순서 변경
      • 장소 카드(주소, 메모, 예약번호, 링크)와 지도 보기
      • 일정 간 이동 시간 표시(직선거리 근사 또는 지도 API)
      • 인쇄/PDF, 캘린더 파일(.ics) 내보내기
    • 기술: PWA + Leaflet(OpenStreetMap)
    • 난이도: ★★★

    5-2. 오프라인 여행 가이드북 생성기

    • 목표: 여행 일정과 정보를 한 권의 모바일 문서로 묶어 오프라인에서도 열어 볼 수 있게 합니다.
    • 핵심 기능
      • 항공·숙소·교통 예약 정보 입력, 일정표 자동 배치
      • 오프라인 지도 타일·장소 메모 캐시
      • 현지 비상 연락처, 유용한 회화, 환전 메모
      • 단일 HTML/PDF 내보내기
    • 기술: PWA + Service Worker
    • 난이도: ★★★

    5-3. 여행 짐 싸기 체크리스트

    • 목표: 여행 유형과 기간, 날씨에 맞춰 짐 목록을 자동 구성합니다.
    • 핵심 기능
      • 여행 유형(해외·국내, 사진 촬영, 트레킹) 선택 시 기본 목록 제공
      • 날씨 기반 의류 수량 추천
      • 사진 장비 패킹(2-8 장비 목록과 연동)
      • 과거 여행의 "빠뜨린 물건" 학습
    • 기술: 단일 HTML
    • 난이도: ★

    5-4. 여행 경비 기록 & 정산기

    • 목표: 여행 중 지출을 빠르게 기록하고 여러 통화로 환산하며 동행인과 정산합니다.
    • 핵심 기능
      • 금액·통화·카테고리 빠른 입력, 일별·카테고리별 통계
      • 환율 자동 반영(수동 입력도 지원)
      • 동행인별 부담액 계산, 최소 송금 횟수 정산
      • 예산 대비 진행률
    • 기술: PWA + IndexedDB + 환율 API
    • 난이도: ★★★

    5-5. 여행 사진 지도 & 여행 기록 자동 생성기

    • 목표: 여행 사진의 GPS와 시간 정보로 이동 경로와 여행 일지 초안을 자동으로 만듭니다.
    • 핵심 기능
      • 사진 EXIF GPS → 지도 위 경로·핀 표시
      • 날짜별 방문 장소 요약, 대표 사진 선택
      • 이동 거리·방문 국가/도시 수 통계
      • 여행기 초안 생성(Claude 활용)
    • 기술: 단일 HTML + exifr + Leaflet
    • 난이도: ★★★
    • 포인트: 사진 취미와 여행을 결합하는 가장 매력적인 아이디어입니다.

    5-6. 여행지 후보 비교 & 의사결정 도구

    • 목표: 여러 여행지 후보를 기준별 가중치로 비교하여 선택을 돕습니다.
    • 핵심 기능
      • 평가 기준(비용, 날씨, 거리, 음식, 사진 촬영 적합도) 설정
      • 가중치 합산 점수, 레이더 차트
      • 월별 날씨·항공권 가격 메모
      • 동행인별 선호도 반영
    • 기술: 단일 HTML + Chart.js
    • 난이도: ★★
    • 참고: 다기준 의사결정(AHP) 방법론을 적용하면 통계 전공과도 연결됩니다.

    5-7. 방문한 곳 기록 지도 (세계/한국 스크래치 맵)

    • 목표: 다녀온 국가와 도시를 지도에 색칠하고 여행 통계를 쌓습니다.
    • 핵심 기능
      • 국가·시도 클릭으로 방문 표시, 방문 횟수·날짜 기록
      • 방문 국가 수, 대륙별 비율, 여행 일수 합계
      • 공유용 이미지 내보내기
      • 가고 싶은 곳 위시리스트
    • 기술: 단일 HTML + SVG 지도(TopoJSON)
    • 난이도: ★★

    5-8. 시차·환율·날씨 한눈에 보는 여행 대시보드

    • 목표: 여행지의 현지 시간, 환율, 날씨, 일출·일몰을 한 화면에 모아 보여 줍니다.
    • 핵심 기능
      • 여행지 목록별 시차와 현지 시각
      • 환율 계산기(원화↔현지통화), 팁·세금 계산
      • 7일 날씨 예보, 일출·일몰(2-2와 연동)
      • 숫자 입력 시 가격 감각 도우미("이 가격은 원화로 얼마?")
    • 기술: 단일 HTML + 무료 날씨·환율 API
    • 난이도: ★★

    5-9. 여행 후기 자동 정리 & 여행기 블로그 초안 도구

    • 목표: 메모와 사진, 일정으로 여행기를 쉽게 정리합니다.
    • 핵심 기능
      • 일자별 짧은 메모 입력(음성 입력 지원)
      • 사진·장소·지출을 합쳐 일기 형식으로 구성
      • Claude로 문장 다듬기와 제목·해시태그 제안
      • Markdown/HTML 내보내기
    • 기술: 웹 앱 + Claude API
    • 난이도: ★★★

    5-10. 여행 분석: 지난 여행에서 배우는 나의 여행 스타일

    • 목표: 과거 여행 데이터를 모아 나의 선호(속도, 예산, 활동 유형)를 분석합니다.
    • 핵심 기능
      • 여행별 일수, 비용, 이동 거리, 방문지 수 등 입력(또는 앱 데이터에서 가져오기)
      • 일일 평균 지출, 만족도와 요인의 관계(회귀분석 활용)
      • "내가 만족했던 여행의 공통점" 요약
      • 다음 여행 계획 추천 포인트
    • 기술: Streamlit + Pandas
    • 난이도: ★★
    • 포인트: 개인 데이터로 통계 분석을 직접 해 보는 재미있는 프로젝트입니다.

    통합 아이디어: "나의 취미 데이터 허브"

    여러 앱의 데이터를 한곳에 모으면 취미 전체를 분석할 수 있습니다.

    연결 내용
    사진(2-1) + 여행(5-5) 여행 사진의 EXIF·GPS로 경로와 촬영 습관을 함께 분석
    언어(3-2) + 독서(4-1) 읽은 책에서 만난 단어를 바로 단어장에 추가
    여행(5-1) + 언어(3-9) 여행지 언어의 필수 회화를 일정에 자동 첨부
    음악(4-4) + 여행(5-5) 여행 기간에 들은 음악을 여행 기록에 연결
    모든 앱 공통 JSON 저장 형식을 정하면 Streamlit 대시보드 하나로 통합 분석 가능

    바이브 코딩 시작 팁

    1. 작게 시작하기: 위 앱의 "핵심 기능" 중 2~3개만 포함한 최소 버전(MVP)을 먼저 만드세요.
