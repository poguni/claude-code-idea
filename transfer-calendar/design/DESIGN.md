## 1. 핵심 원칙: 테마 2종

원고지와 플래너 두 테마는 **화면 구조, 기능, 컴포넌트, 정보 배치가 모두 같습니다.** 달라지는 것은 3장의 **디자인 토큰**(색, 글꼴, 모서리, 그림자, 칩 모양)뿐입니다.

1. **컴포넌트는 토큰만 참조합니다.** 색·글꼴·모서리 값을 컴포넌트 코드에 직접 쓰지 않고 CSS 변수(`var(--accent)` 등)로만 씁니다.
2. **테마는 루트 속성 하나로 바뀝니다.** `<html data-theme="wongoji|planner">`. 테마별 차이는 토큰 값과 1.1의 예외 규칙뿐입니다.
3. **대학 색은 테마와 따로 관리합니다.** 대학 12색(4장)은 두 테마에서 같은 값을 씁니다.
4. **정보 위계는 같습니다.** 시험 당일 가장 크게 보일 것은 어느 테마든 "입실 시각 · 권장 출발 시각 · D-day"입니다.
5. **두 테마 모두 밝은 화면입니다.** 다크 모드는 이번 범위에서 제외합니다(기기가 다크 모드여도 선택한 테마를 그대로 보여 줌). 필요해지면 v0.1의 B안(새벽 4시) 토큰을 다크 테마로 추가합니다.

### 1.1 테마별 예외 규칙(허용 목록)
토큰으로 표현하기 어려운 차이는 아래만 허용합니다. 늘릴 때는 이 표에 먼저 적습니다.

| 테마 | 예외 | 이유 |
|---|---|---|
| 플래너 | 달력 칸 사이 3px 간격, 칸마다 둥근 흰 카드(선 없음) | 다이어리 스티커 느낌 |
| 플래너 | 대학 약칭 배지·일정 추가 버튼을 원형으로 | 둥근 형태 언어 |

### 1.2 테마 선택
- 위치: 더보기 › 설정 › **테마**. 두 테마를 작은 미리보기 카드(바탕색, 강조색, 제목 글꼴 "편입 캘린더", 칩 2개)로 보여 주고 눌러서 고릅니다.
- 고르면 바로 적용합니다(새로고침 없음). 기본값은 **원고지**입니다.
- 테마는 사람·기기마다 다를 수 있으므로 **기기(localStorage, 키 `tcal.theme`)에 저장**합니다. 가족 공유 데이터(Supabase)에는 넣지 않습니다.
- 첫 화면이 그려지기 전에 `<head>`의 짧은 스크립트로 `data-theme`를 먼저 지정해, 다른 테마가 잠깐 보이는 깜빡임을 막습니다.
- PWA 상태 표시줄 색(`<meta name="theme-color">`)도 테마의 `--bg`로 함께 바꿉니다.

## 3. 디자인 토큰

### 3.1 색 토큰
| 토큰 | 용도 | 원고지 | 플래너 |
|---|---|---|---|
| `--bg` | 화면 바탕 | #F7F5F0 | #F3F0FA |
| `--surface` | 카드·달력·탭 막대 | #FFFFFF | #FFFFFF |
| `--surface-2` | 보조 면(월 탭 바탕, 시간 상자) | #EFECE4 | #E9E3F7 |
| `--text` | 본문 | #1C1B19 | #2A2340 |
| `--muted` | 보조 글자 | #5F5B53 | #625A7A |
| `--line` | 선 | #DDD8CC | #DCD4EE |
| `--accent` | 주요 버튼, D-day, 권장 출발, 선택 | #2B59C3 | #C93F4A |
| `--accent-ink` | 강조색 위 글자 | #FFFFFF | #FFFFFF |
| `--accent-soft` | 강조 배경(D-day 배지, 안내 상자) | #E3EAF8 | #FBE3E4 |
| `--sun` | 일요일·공휴일 날짜 | #C62828 | #C93F4A |
| `--sat` | 토요일 날짜 | #1F57C3 | #4F46E5 |
| `--danger` / `--danger-soft` | 시간 충돌 | #C62828 / #FBE4E2 | #C0262D / #FCE1E2 |
| `--warn` / `--warn-soft` | 간격 주의 | #A14A00 / #FBEBD9 | #9A4A00 / #FDEBD6 |
| `--today` | 오늘 날짜 원 | = accent | = accent |

- 본문 글자와 바탕의 대비는 4.5:1 이상입니다. `--muted`도 각 바탕에서 4.5:1 이상이 되도록 골랐습니다.
- 위험 표시는 색만 쓰지 않습니다. 항상 ⚠ 아이콘과 문구("시간 충돌", "간격 주의")를 함께 둡니다.

### 3.2 글꼴 토큰
| 토큰 | 쓰임 | 원고지 | 플래너 |
|---|---|---|---|
| `--font` | 본문·작은 글씨(17px 이하): 본문, 라벨, 목록, 칩, 입력창, 카드 제목 | IBM Plex Sans KR | **Pretendard** |
| `--font-display` | 제목(18px 이상): 앱바 제목, 시트 제목, 인쇄 머리글 | IBM Plex Sans KR 700 | **Gowun Dodum 400** |
| `--font-num` | 큰 숫자(18px 이상): D-day, 시간 상자의 입실·권장 출발 | IBM Plex Mono 600 | **Gowun Dodum 400** |
| `--font-num-sm` | 작은 숫자(17px 이하): 달력 날짜, 수험 번호, 시작~종료, 요약 수치 | IBM Plex Mono 600 | **Pretendard 600 + tabular-nums** |
| `--display-w` | 제목 굵기 | 700 | 400 |

**플래너 글꼴 규칙**
- 기준은 **18px**입니다. 18px 이상의 제목과 큰 숫자는 고운돋움, 17px 이하는 모두 프리텐다드입니다.
- 고운돋움은 굵기가 400 하나뿐입니다. `font-weight: 700`을 주면 브라우저가 가짜 굵게(faux bold)를 만들어 글자가 뭉개지므로 **굵기를 바꾸지 않고 크기로 위계를 만듭니다**(`font-synthesis: none`).
- 프리텐다드는 400, 500, 600, 700을 씁니다. 숫자에는 `font-variant-numeric: tabular-nums`를 적용해 시각이 세로로 나란히 맞게 합니다.

**글꼴 불러오기**
| 글꼴 | 시안(design-mockup.html) | 앱 구현 |
|---|---|---|
| IBM Plex Sans KR, IBM Plex Mono, Gowun Dodum | Google Fonts | Google Fonts(`display=swap`) 또는 `@fontsource` 패키지로 자체 호스팅 |
| Pretendard | jsDelivr CDN `orioncactus/pretendard@v1.3.9` 가변 글꼴(dynamic subset) | npm `pretendard` 패키지로 자체 호스팅(dynamic subset), 버전 고정 |

- 대체 글꼴: `-apple-system, "Apple SD Gothic Neo", sans-serif`.
- 테마에서 쓰지 않는 글꼴은 불러오지 않습니다. 원고지일 때는 Plex 계열, 플래너일 때는 Pretendard·Gowun Dodum만 불러옵니다.

## 4. 대학 색과 일정 표기

### 4.1 대학 12색 (두 테마 공통)
등록 순서대로 배정하고, 대학 입력 폼에서 바꿀 수 있습니다. 모두 흰 글자와 대비 4.5:1 이상입니다.

| # | 색 | 값 | # | 색 | 값 |
|---|---|---|---|---|---|
| 1 | 파랑 | #1D4ED8 | 7 | 황토 | #B45309 |
| 2 | 주황 | #C2410C | 8 | 회청 | #475569 |
| 3 | 초록 | #047857 | 9 | 자홍 | #A21CAF |
| 4 | 보라 | #6D28D9 | 10 | 올리브 | #4D7C0F |
| 5 | 분홍 | #BE185D | 11 | 갈색 | #7C2D12 |
| 6 | 청록 | #0E7490 | 12 | 남보라 | #4338CA |

- 색이 비슷한 대학이 있어도 구분되도록 **약칭을 항상 함께** 표시합니다(색만으로 구분하지 않음).
- 약칭은 2~3자를 권장합니다. 4자는 달력 칸에서 말줄임될 수 있습니다.

### 4.2 일정 종류 기호와 칩
| 종류 | 기호 | 달력 칩 | 인쇄 |
|---|---|---|---|
| 필기시험 | ● | **채움**(대학 색 바탕 + 흰 글자) | 채움 태그 + 입실 시각 |
| 면접 | ◆ | **채움** | 채움 태그 + 입실 시각 |
| 원서 접수, 서류 마감, 등록금 납부 | ▲ | 테두리(대학 색 1.5px + 본문색 글자) | 테두리 태그 + "시작/마감" |
| 고사장·1단계·최종·충원 발표 | ○ | 테두리 | 테두리 태그 + 종류 |
| 기타 | · | 테두리 | 테두리 태그 |

- 칩 형식: `기호 + 약칭`(예: `●건국`). 높이 15px, 칸 하나에 최대 3개(공휴일 칸은 2개), 넘치면 `+N`.
- 기간 일정은 시작일과 마감일 칸에만 표시합니다.

## 5. 레이아웃 (아이폰 15 Pro, 393×852)

```text
┌──────────────── 393 ────────────────┐
│ 상태 표시줄·다이내믹 아일랜드  59      │  env(safe-area-inset-top)
│ 앱바: 편입 캘린더 · [인쇄] [+ 추가] 52 │
│ D-day 카드                    ≈ 56   │
│ 겹침 알림(있을 때)             ≈ 34   │
│ 월 탭 11월|12월|1월|2월        ≈ 48   │
│ 달마다 요약 + 요일 머리글       ≈ 40   │
│ 달력 5주 × 78px / 6주 × 66px  ≈ 396  │  ← 한 달이 스크롤 없이 보이는 것이 목표
│ 범례                          ≈ 22   │
│ 하단 탭 막대 56 + 홈 인디케이터 34     │  env(safe-area-inset-bottom)
└─────────────────────────────────────┘
```

- 앱바 제목은 "편입 캘린더"입니다. 영문 이름 "TExam Calendar"는 홈 화면 아이콘 이름이 아닌 곳(설정 › 앱 정보, 인쇄 바닥글, .ics 캘린더 정보)에 씁니다.
- 달력 칸 폭은 (393 − 24) ÷ 7 ≈ 52px입니다. 칸 높이는 5주인 달(11·12·2월) 78px, 6주인 1월 66px입니다.
- "일정 추가"는 떠 있는 버튼(FAB)이 아니라 **앱바 오른쪽 버튼**으로 둡니다. 떠 있는 버튼은 토요일 칸을 가립니다.
- 날짜를 누르면 **바텀 시트**(최대 높이 80%)가 올라옵니다. 바깥을 누르거나 닫기 버튼, 아래로 끌기로 닫습니다.
- 데스크톱(1024px 이상)은 왼쪽 메뉴 + 달력 + 오른쪽 상세 패널입니다. 바텀 시트 내용이 오른쪽 패널에 그대로 들어갑니다. 1440px 이상에서는 네 달 2×2 전체 보기를 쓸 수 있습니다.

## 6. 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| 앱바 | 제목(display) 왼쪽, 아이콘 버튼 44×44 오른쪽. 하위 화면은 왼쪽에 뒤로/닫기 |
| D-day 카드 | 왼쪽 큰 숫자(`--font-num` 28px, `--accent`), 오른쪽 "약칭 + 종류", "날짜 입실 · 출발". 누르면 그날 시트 |
| 겹침 알림 | `--danger-soft` 바탕, ⚠ + "겹치는 시험 N건(충돌 a · 주의 b) · 날짜들". 누르면 첫 날짜 시트 |
| 월 탭 | 4칸 분할 컨트롤. 선택: `--surface` + 그림자 |
| 달력 칸 | 날짜 숫자(`--font-num-sm` 12px, 오늘은 `--today` 원), 공휴일 이름(9px), 겹침 아이콘(오른쪽 위 14px: 충돌 `--danger`, 주의 `--warn`), 칩 최대 3개 |
| 하단 탭 막대 | 달력 · 대학 · 서류 · 더보기. 아이콘 24px + 11px 라벨, 선택은 `--accent` |
| 일정 카드(시트) | 위쪽 5px 대학 색 띠 → 배지(기호 · 약칭 · 종류) + D-day 배지 → 대학·학과 → **시간 상자 3칸(입실 / 시작~종료 / 권장 출발)** → 정보 행(수험 번호·장소·교통·접수처, 각 행에 복사/지도/전화 버튼) → 준비물 체크(2열) → [대학 상세] [캘린더에 추가] |
| 정보 행 | 라벨 72px / 값 / 작은 버튼. 높이 최소 44px, 위쪽 1px 선 |

## 8. 인쇄 규칙 (A4)

| 항목 | 세로형(한 달 한 장) | 가로형(두 달 한 장) |
|---|---|---|
| 용지·여백 | A4 세로, 10mm | A4 가로, 8mm |
| 머리글 | "2027 편입 시험 일정 · 2026년 12월" 18pt + 인쇄 날짜 8pt, 아래 2pt 강조선 | 같은 형식, "11월·12월" |
| 달력 행 | 그 달의 주 수(5 또는 6) | 두 달 모두 6행으로 맞춤 |
| 칸 내용 | 날짜 9pt, 일정 7.5pt: `태그(기호+약칭) 종류/시각 수험번호` 최대 4개 | 일정 6.5pt, 최대 3개, 수험 번호 없음 |
| 범례 표 | 그 달 시험·면접 대학: 대학·학과·수험 번호·시험 일시·장소 | 대학·수험 번호·시험 일시 |
| 바닥글 | 기호 설명 7pt "● 필기 ◆ 면접 ▲ 마감 ○ 발표 · 시각은 입실 시각" + "편입 캘린더(TExam Calendar)" | 같음 |

- **바탕은 두 테마 모두 흰색**입니다(잉크 절약). 테마는 글꼴과 머리글 강조선 색(원고지 파랑, 플래너 코랄)에만 반영합니다. 플래너는 머리글을 고운돋움, 칸 안 글자를 프리텐다드로 씁니다.
- 칸 선 0.3mm 회색(#999), 일요일·공휴일 #B71C1C, 토요일 #1A47A8.
- 흑백 모드: 대학 색 대신 시험·면접은 검정 채움, 나머지는 검정 테두리. 범례 표의 색 견본을 숨깁니다.
- 크기는 mm·pt로만 지정하고 `print-color-adjust: exact`, `break-inside: avoid`를 씁니다.

## 9. 상호작용과 움직임
- 바텀 시트: 아래에서 위로 220ms(ease-out), 배경 어둡게 35%.
- 월 이동: 좌우 밀기, 160ms 가로 이동. `prefers-reduced-motion`이면 움직임 없이 바꿈.
- 테마 전환: 색·모서리만 150ms 전환. 글꼴은 전환 효과 없이 바로 바꿈.
- 버튼 누름: 배경 `--surface-2`로 바뀜(호버 대신). 키보드 초점은 2px `--accent` 윤곽선.
- 수험 번호 복사 후 아래쪽에 1.5초 안내("수험 번호를 복사했습니다").

## 10. 접근성 체크리스트
- 터치 영역 44×44px 이상(달력 칸은 52×66px 이상).
- 달력 칸 버튼의 `aria-label`: "1월 10일, 일정 2개, 간격 주의".
- 바텀 시트는 `role="dialog"`, 열리면 제목으로 초점 이동, 닫으면 누른 칸으로 초점 복귀.
- 색 외 구분 수단: 약칭, 기호(●◆▲○), 경고 문구.
- 입력창 16px 이상, 라벨 연결(`<label for>`).
- 테마 선택 카드는 라디오 그룹(`role="radiogroup"`)으로 만들어 키보드로 고를 수 있게 함.

## 11. 구현 메모(Claude Code용)
- 토큰은 `src/styles/themes.css`에 `[data-theme="wongoji"]`, `[data-theme="planner"]` 블록으로 둡니다. 값은 3장의 표와 `design-mockup.html`의 `.tc[data-t="a"]`(원고지), `.tc[data-t="c"]`(플래너) 블록과 같습니다.
- Tailwind를 쓸 때는 `theme.extend.colors`에 `bg: 'var(--bg)'`처럼 변수로 연결하고, 글꼴도 `fontFamily: { body: 'var(--font)', display: 'var(--font-display)', num: 'var(--font-num)', 'num-sm': 'var(--font-num-sm)' }`로 연결해, 테마를 바꿔도 클래스는 그대로 둡니다.
- 테마 목록은 `src/lib/themes.ts`에 `{ id: 'wongoji', name: '원고지' }, { id: 'planner', name: '플래너' }`로 두어, 나중에 테마를 더해도 설정 화면이 자동으로 늘어나게 합니다.
- 대학 색 12개는 `src/lib/colors.ts`의 상수로 두고, DB `tcal_universities.color`에는 값(hex)을 저장합니다.
- 시안의 일정·대학은 모두 가상 예시 데이터입니다. 실제 앱에서는 쓰지 않습니다.
