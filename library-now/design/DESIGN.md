| 항목 | 내용 |
|---|---|
| 문서 버전 | v0.2 |
| 작성일 | 2026-11-18 (v0.2 수정: 2026-11-18) |
| 기준 문서 | `docs/PRD.md` (PRD v0.2) |
| 결정 사항 | **세 테마 모두 구현, 기본 테마는 서재** |

| 기준 화면 | 데스크탑 1440×900, 스마트폰 390×844 |

> 시안에 나오는 도서관 이름, 운영시간, 거리, 전화번호는 화면 구성을 보여 주기 위한 **예시 데이터**입니다. 실제 데이터는 M0 단계에서 수집합니다.

---

## 1. 디자인 원칙

1. **3초 판단**: 화면을 열면 "어디가 열렸고, 지금 가면 몇 시간 쓸 수 있는지"가 가장 먼저 보입니다. 남은 이용 시간은 카드마다 가장 큰 숫자로 표시합니다.
2. **상태는 색 + 기호 + 글자**: 색만으로 상태를 구분하지 않습니다(색각 이상 사용자 배려).
3. **화면 전체 폭 사용**: 데스크탑에서 가운데 좁은 기둥 배치를 쓰지 않습니다. 목록·지도·상세 3단을 화면 끝까지 채웁니다.
4. **테마는 옷만 바꿉니다**: 세 테마는 **같은 HTML 구조와 같은 크기 체계**를 쓰고, 색·글꼴·모서리·장식만 다릅니다. 그래서 앱 안에서 테마를 바꿔도 기능과 배치가 그대로입니다.

## 2. 테마 시스템

### 2.1 세 가지 테마

| 테마 | 이름 | 분위기 | 핵심 장치 |
|---|---|---|---|
| A (기본) | **서재 (Stacks)** | 오래된 도서관, 종이, 녹색 스탠드, 놋쇠 | 아이보리 종이 바탕, 짙은 녹색 상단 바, 명조 제목, 색인 카드(가는 줄 + 붉은 선), 도장 모양 배지, 책등 모양 마커 |
| B | **말랑 (Soft)** | 파스텔, 부드럽고 귀여움 | 라벤더 바탕, 둥근 모서리(18px), 둥근 글꼴(주아), 민트·피치·핑크 배지, 점선 테두리 강조 상자, 동그란 달력 날짜 |
| C | **모노 (Mono)** | 모던, 세련, 정보 밀도 | 회백색 바탕, 검정 상단 바, 코발트 블루 강조, 기하학 숫자 글꼴, 검정 외곽선 선택 표시, 각진 마커 |

### 2.2 구현 방식
- 테마는 최상위 요소의 클래스(또는 `data-theme` 속성) 하나로 바꿉니다.
  ```html
  <html data-theme="library">  <!-- library | pastel | mono -->
  ```
- 모든 색·글꼴·모서리는 **CSS 변수(토큰)**로만 참조합니다. 컴포넌트 CSS에 색 값을 직접 쓰지 않습니다.
- 테마별 장식(색인 카드 줄, 점선 테두리 등)은 `[data-theme="library"] .card { … }`처럼 테마 범위 안에서만 덧붙입니다. **장식은 크기와 배치를 바꾸지 않아야** 합니다(예외: 2.4 참고).
- 사용자가 고른 테마는 `localStorage`의 `ln.settings.theme`에 저장합니다. **기본값은 `library`(서재)**입니다. 저장값이 없거나 읽을 수 없으면 서재를 씁니다.
- 테마가 깜박이며 바뀌지 않도록, `index.html`의 `<head>`에서 작은 인라인 스크립트로 저장된 테마를 읽어 `data-theme`을 먼저 설정합니다.
- 테마 전환 위치: 설정 화면의 "화면 테마" 항목(라디오 3개, 각 테마의 작은 미리보기 포함).

### 2.4 테마별 장식 (허용 범위)

| 장식 | 서재 | 말랑 | 모노 |
|---|---|---|---|
| 도서관 카드 | 색인 카드: 가는 하늘색 줄 + 상태 줄 위 붉은 선 | 테두리 없는 흰 카드 + 부드러운 그림자 | 1px 선, 그림자 없음 |
| 선택된 카드 | 녹색 테두리 + 옅은 링 | 라벤더 테두리 + 링 | **검정 2px 외곽선** |
| 상태 배지 | 도장 모양(외곽선, 명조) | 꽉 찬 파스텔 알약 | 꽉 찬 사각 배지(6px) |
| 지도 마커 | 책등 모양 세로 직사각형(24×32) | 굵은 흰 테두리 원(30) | 둥근 사각형(30, 모서리 8px) |
| "지금 가면" 상자 | 짙은 녹색 + 놋쇠 숫자 | 연보라 + 점선 테두리 | 검정 + 흰 숫자(36px) |
| 달력 날짜 | 사각 | 원형 | 사각 |
| 소제목 | 명조 + 밑줄 | 기본 | 대문자 간격 넓힘 |

- 마커 크기만 테마마다 조금 다르며(서재 24×32, 나머지 30×30), 클릭 영역은 모두 최소 44×44px로 맞춥니다(투명 패딩).

### 2.5 실제 지도 타일과 테마
시안의 지도는 그림이지만, 실제 앱은 OpenStreetMap 타일 이미지를 씁니다. 타일 색은 바꿀 수 없으므로 **타일 레이어에만 CSS 필터**를 걸어 테마 분위기를 맞춥니다.

| 테마 | 타일 필터(제안, 구현 시 조정) |
|---|---|
| 서재 | `sepia(.25) saturate(.85) brightness(1.02)` |
| 말랑 | `saturate(.75) brightness(1.04) hue-rotate(-8deg)` |
| 모노 | `grayscale(.85) contrast(1.05)` |

- 필터는 `.leaflet-tile-pane`에만 적용하고, 마커·팝업에는 적용하지 않습니다.
- 카카오맵으로 바꿀 때도 같은 방식(지도 타일 영역에만 필터)을 씁니다.

## 4. 레이아웃

### 4.1 반응형 구간

| 구간 | 너비 | 배치 |
|---|---|---|
| 데스크탑 | 1200px 이상 (기준 1440×900) | 상단 바 + 목록 · 지도 · 상세 **3단** |
| 태블릿 | 768~1199px | 상단 바 + 목록 · 지도 2단, 상세는 오른쪽 서랍 |
| 스마트폰 | 767px 이하 (기준 390×844) | 전체 화면 지도 + 바텀 시트 + 아래 탭 바 |

### 4.2 데스크탑 (1440×900)
```
┌ 상단 바 64px ───────────────────────────────────────────────────────────┐
│ 로고·앱 이름 │ 지역 칩 ×3 + 내 주변 │ 모드 [책 빌리기|공부하기] │ ··· │ 출발 │ 기준 시각 │ 설정 │
├──────────────┬──────────────────────────────────────┬──────────────────┤
│ 목록 360px    │ 지도 (나머지 전부, 1440 기준 680px)     │ 상세 400px        │
│ 검색 44       │ 오른쪽 위: 확대/축소, 내 위치/전체 보기   │ 탭 48 (상세|달력)   │
│ 필터 칩 32    │ 왼쪽 아래: 범례                         │ 이름·배지          │
│ 개수·정렬     │ 오른쪽 아래: OSM 출처                    │ "지금 가면" 상자    │
│ 카드 목록     │ 선택 마커 위 팝업                       │ 길찾기 버튼 44      │
│ (세로 스크롤)  │                                       │ 운영시간 표·휴관 규칙 │
│              │                                       │ 미니 달력 · 출처     │
└──────────────┴──────────────────────────────────────┴──────────────────┘
```
- 화면 높이를 꽉 채우고(`height: 100dvh`), 각 열이 각자 세로로 스크롤합니다. 페이지 전체 스크롤은 없습니다.
- 1440px보다 넓으면 지도만 넓어집니다. 목록은 최대 420px, 상세는 최대 480px까지 비례해 늘립니다.
- 상세 패널을 접으면 지도가 그만큼 넓어집니다(접기 버튼은 탭 줄 오른쪽 끝).

### 4.3 스마트폰 (390×844)
```
┌ 상단 영역 약 158px ─────────────┐
│ 로고·앱 이름            [검색]    │
│ [  책 빌리기  |  공부하기  ]      │ 모드 세그먼트 높이 42
│ [출발 집] [기준 지금] [지역 …]    │ 가로 스크롤 칩 34
├────────────────────────────────┤
│ 지도 (보이는 영역 약 210px)  [◎] │ 내 위치 버튼 48
├ 바텀 시트 (기본 416px) ─────────┤
│ ── 손잡이                       │
│ 지금 열린 곳 5곳        [거리순] │
│ [전체][지금 열린 곳만][21시…]    │
│ 카드 ×3 (스크롤)                │
├ 탭 바 64px ─────────────────────┤
│ 지도 · 목록 · 달력 · 설정         │
└────────────────────────────────┘
```
- 바텀 시트는 3단계로 멈춥니다: 낮게(손잡이+제목만, 약 120px) / 기본(416px) / 전체(상단 영역 아래까지).
- 도서관을 고르면 시트 내용이 상세 화면으로 바뀌고, 맨 아래에 **카카오맵으로 길찾기** 버튼을 크게 고정합니다.
- 아이폰 아래 홈 표시줄 영역은 `env(safe-area-inset-bottom)`만큼 탭 바에 여백을 더합니다.

### 4.4 간격 체계
- 기본 단위 4px. 자주 쓰는 값: 4, 6, 8, 10, 12, 14, 16, 20, 24px.
- 패널 안쪽 여백: 목록 16px, 상세 20px, 스마트폰 16px.
- 카드 사이 10px(스마트폰 8px), 카드 안쪽 12×14px.

## 5. 컴포넌트 명세

모든 컴포넌트는 세 테마가 같은 구조와 크기를 씁니다. 클래스 이름은 시안 HTML 기준입니다.

### 5.1 상단 바 `.top` (데스크탑) / `.mtop` (스마트폰)
- 데스크탑 높이 64px, 좌우 여백 20px, 요소 간격 14px.
- 지역 칩 `.tchip`: 높이 36px, 여러 개 선택 가능(`aria-pressed`). 선택 시 `--top-on` 바탕.
- 모드 세그먼트 `.seg`: 두 버튼, 선택된 쪽만 `--top-on`. 스마트폰은 가로 꽉 차게(`.mseg`).
- 출발지 칩: "출발" 작은 라벨 + 아이콘 + 이름 + 펼침 화살표. 누르면 현재 위치/집/직장 목록.
- 기준 시각 칩: "지금 · 11월 18일(수) 19:05". 누르면 날짜·시각 선택(P1).
- 설정 버튼: 40×40 아이콘 버튼, `aria-label="설정"`.

### 5.2 검색창 `.search`
- 높이 44px, 돋보기 아이콘 + 입력창. `<label>`로 감싸고 숨김 라벨 제공.

### 5.3 필터 칩 `.fchip`, 정렬 버튼 `.sort`
- 필터 칩 높이 32px. 선택 시 `--accent-soft` 바탕 + `--accent` 테두리 + 굵게.
- 정렬: "거리순 / 남은 시간순 / 이름순" 메뉴.
- 목록 위 요약 줄: "문 연 곳 **5** / 7곳 · 열람실 기준" (모드에 따라 "자료실 기준").

### 5.4 도서관 카드 `.card`
```
┌──────────────────────────────────────────┐
│ 도서관 이름 (16px)              2시간 38분 │ ← 남은 이용 시간(18px, 숫자 글꼴)
│ 구 · 거리 · 이동 시간 (12px)       이용 가능 │
│ [● 운영 중]  열람실 22:00까지          ☆   │ ← 배지 · 마감 정보 · 즐겨찾기
└──────────────────────────────────────────┘
```

| 변형 | 오른쪽 숫자 | 배지 | 모양 |
|---|---|---|---|
| 운영 중 | 이용 가능 시간 | ● 운영 중 | 기본 |
| 곧 닫힘 | 도착 후 이용 시간(30분 미만이면 `--soon` 색) | ◔ 곧 닫힘 · ○분 남음 | 기본 |
| 곧 열림 | 개관 시각 | ○ 09:00 개관 | 기본 |
| 운영 종료 | 다음 개관 시각 + "내일 개관" | ◐ 오늘 운영 종료 | `.off` (바탕 `--surface-2`, 그림자 없음) |
| 휴관 | 다음 개관 시각 | ✕ 오늘 휴관 + 사유 | `.off` |
| 선택됨 | — | — | `.sel` (강조 테두리 + 링) |

- 카드 전체를 누르면 선택됩니다. 구현 시 카드 안에 이름 버튼을 두고 카드 전체로 클릭 영역을 넓힙니다(별 버튼과 중첩 버튼이 되지 않게).
- 목록에서 카드에 마우스를 올리면 지도 마커가 강조됩니다.

### 5.5 상태 배지 `.badge`
- 높이 24px(말랑 26px), 좌우 9px, 12px 굵게, 기호 + 글자.
- 기호: 운영 중 ●, 곧 닫힘 ◔, 곧 열림 ○, 운영 종료 ◐, 휴관 ✕, 정보 없음 ?
- 상태 클래스 `.s-open` 등이 `--b-fg`, `--b-bg`를 정하고, 배지·마커·범례가 이 두 변수를 함께 씁니다.

### 5.6 지도 마커 `.mk`
- 상태색 원(또는 테마별 모양) + 흰 책 아이콘 + 옆에 작은 꼬리표(남은 시간 또는 "휴관").
- 선택된 마커 `.sel`: 44px로 커지고 `--accent-ring` 6px 링, 꼬리표 대신 팝업 표시.
- 출발지 마커 `.origin`: `--text` 색 사각형 + 집/회사 아이콘 + 이름 꼬리표.
- 출발지와 선택 도서관 사이에 점선(`--accent`, 3.5px)을 그립니다. 실제 경로가 아니라 방향 표시입니다.
- 마커가 겹치면 꼬리표를 숨기고, 확대 수준이 낮으면 묶음(클러스터) 표시를 검토합니다(서울 전체 확대 시).

### 5.7 지도 팝업 `.pop`, 컨트롤 `.ctrls`, 범례 `.legend`
- 팝업: 너비 240px, 이름 + 배지 + "지금 가면 ○시간 ○분 이용 가능".
- 컨트롤: 44×44 버튼 묶음 2개(확대/축소, 내 위치/전체 보기), 오른쪽 위 16px.
- 범례: 왼쪽 아래, 다섯 상태의 색 점 + 이름.
- 출처: 오른쪽 아래 "© OpenStreetMap contributors" (항상 표시).

### 5.8 상세 패널 `.detail`
1. **탭** (48px): 상세 / 휴관 달력. 선택 탭은 아래 2px 강조선.
2. **헤더**: 이름(22px), "구 · 소속 · 전화", 배지 + 다른 실 정보("자료실 20:00까지"), 즐겨찾기 별.
3. **"지금 가면" 상자 `.hero`**: "지금 출발하면" → 큰 숫자 "2시간 38분 이용 가능" → 오른쪽 "열람실 22:00 마감".
   - **시간 막대 `.track`**: 이동 구간은 빗금, 이용 가능 구간은 `--hero-accent`. 길이는 (도착−지금) : (마감−도착) 비율.
   - 눈금: "19:05 지금 · 19:22 도착 · 도보 17분 · 22:00 마감".
4. **행동 버튼 `.acts`**: [카카오맵으로 길찾기](주 버튼, 44px) + 주소 복사 + 홈페이지(44×44 아이콘 버튼). 스마트폰에서는 네이버 지도 버튼을 추가합니다.
5. **운영시간 표 `.hours`**: 행 = 평일 / 토요일 / 일요일(·공휴일), 열 = 자료실 / 열람실. 오늘 행은 `--accent-soft` 바탕 + 굵게. 아래에 메모(세부 실 시간)와 정기 휴관 규칙.
6. **미니 달력 `.cal`**: 7열 격자, 휴관일 `--closed-bg` 바탕 + `--closed` 글자, 오늘은 `--accent` 2px 안쪽 테두리. 공휴일은 날짜 아래 작은 점과 툴팁(구현 시 추가).
7. **출처 `.src`**: "데이터 기준 2026-11-01 · 홈페이지 확인 2026-11-15".

### 5.9 휴관 달력 탭 (시안에는 미포함, 같은 토큰으로 구현)
- 월 달력 크게(셀 높이 72px), 날짜 칸 안에 즐겨찾기 도서관별 색 점(최대 5개, 넘치면 "+2").
- 즐겨찾기가 없으면 "문 연 곳 n곳" 숫자를 표시합니다.
- 날짜를 누르면 아래에 그날 문 여는 도서관 목록(카드 축소형).

### 5.10 스마트폰 전용
- **바텀 시트 `.sheet`**: 위 모서리 `--sheet-r`, 손잡이 40×5px, 제목 18px + 정렬 버튼, 필터 칩은 가로 스크롤.
- **내 위치 버튼 `.fab`**: 48×48, 시트 바로 위 오른쪽.
- **탭 바 `.tabbar`**: 64px, 4칸(지도·목록·달력·설정), 아이콘 22px + 라벨 11.5px, 선택 탭은 `--accent` 색.

### 5.11 아이콘
- 24px 격자, 선 굵기 1.8, 둥근 끝(`stroke-linecap: round`). 시안은 인라인 SVG로 그렸습니다.
- 구현 시 같은 스타일의 무료 아이콘 세트(Lucide)를 씁니다: `book-open`, `pencil`, `home`, `briefcase`(직장), `search`, `star`, `navigation`, `copy`, `link`, `calendar`, `map`, `list`, `sliders-horizontal`, `locate`, `maximize`, `plus`, `minus`, `ban`(휴관), `chevron-down`.
- 이모지는 쓰지 않습니다.

## 6. 상호작용과 움직임

| 상황 | 동작 |
|---|---|
| 카드에 마우스 올림 | 해당 마커 확대(1.15배) + 꼬리표 강조 |
| 카드·마커 선택 | 지도가 선택 도서관으로 부드럽게 이동(300ms), 상세 패널 갱신 |
| 모드 전환 | 배지·숫자만 교체(페이드 150ms), 목록 순서 재정렬 |
| 바텀 시트 끌기 | 3단계 위치로 스냅(250ms, ease-out) |
| 남은 시간 | 1분마다 다시 계산(화면이 보일 때만) |
| 움직임 줄이기 설정 | `prefers-reduced-motion`이면 이동·페이드 없이 즉시 바꿈 |

## 7. 접근성 체크리스트
- [ ] 모든 버튼은 `<button>`, 링크는 `<a href>`, 입력은 `<label>`과 연결
- [ ] 아이콘만 있는 버튼에 `aria-label` (설정, 주소 복사, 홈페이지, 확대 등)
- [ ] 토글 칩은 `aria-pressed`, 탭은 `role="tab"` + `aria-selected`
- [ ] 상태는 색 + 기호 + 글자로 표시
- [ ] 글자 대비 4.5:1 이상(11~12px 보조 글자 포함), 큰 글자·아이콘 3:1 이상
- [ ] 터치 영역 최소 44×44px
- [ ] 키보드만으로 목록 → 상세 → 길찾기까지 이동 가능, 포커스 표시가 보임
- [ ] 지도 마커도 키보드로 선택 가능(Leaflet 마커에 `keyboard: true`, 대체 텍스트)

## 8. 구현 메모
- 시안 HTML의 `<style>`은 세 부분으로 나뉘어 있습니다: ① 테마 토큰 ② 공통 구조 ③ 테마 장식. 구현 시 ①은 `themes.css`, ②는 컴포넌트별 CSS Modules, ③은 `themes.css` 아래쪽으로 옮깁니다.
- 시안의 지도 그림(SVG)은 실제 Leaflet 지도로 바뀝니다. 마커·팝업·컨트롤·범례의 모양은 그대로 Leaflet `divIcon`과 사용자 정의 컨트롤로 만듭니다.
- 데스크탑 시안은 높이 900px로 고정해 그렸습니다. 실제 앱은 `100dvh`를 씁니다.
- 세 테마를 모두 구현합니다. 새 컴포넌트를 만들 때마다 세 테마에서 모두 확인합니다(특히 대비와 장식이 배치를 바꾸지 않는지).
