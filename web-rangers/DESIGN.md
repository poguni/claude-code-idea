## 1. 콘셉트: 탐정 수첩 × 생물 도감

학생은 생태계에 일어난 사건의 원인을 화살표를 따라 추리하는 **탐정단원**입니다. 화면은 **크라프트지 수첩** 위에 생물 카드와 메모를 붙여 둔 느낌으로 만듭니다.

- **바탕**: 따뜻한 종이색과 옅은 점 격자(수첩 모눈)
- **브랜드 색**: 탐정 코트의 **남색**과 돋보기의 **금색**
- **사건 카드**: 검은 테두리와 각진 그림자로 신문 기사처럼 표현해, 평소 화면과 확실히 구분합니다.
- **생물 색**: 역할(생산자~분해자)마다 고정된 색을 써서 먹이 그물의 층 구조가 한눈에 보이게 합니다.

### 디자인 원칙
1. **화살표가 주인공**: 먹이 그물의 화살표와 영향의 흐름이 가장 눈에 띄어야 합니다. 장식은 그보다 약하게 씁니다.
2. **색만으로 말하지 않기**: 늘어남·줄어듦은 항상 **색 + 기호(▲▼●) + 숫자**로 함께 표시합니다. 역할도 색 + 글자 배지로 표시합니다.
3. **크게, 짧게**: 터치 영역은 최소 48px, 문장은 25자 안팎, 한 화면에 질문 하나에 집중합니다.
4. **교실 친화**: 전자칠판에서 멀리서도 보이도록 대비를 높이고, 기본은 소리 없이 시각 효과로 피드백합니다.

### 6.2 SpeciesCard (생물 카드)
- **작은 카드**(보관함): 46px 그림 상자 + 이름 + 역할 배지. 그림 상자 아래 4px 역할색 띠.
- **도감 카드**: 위 96px 그림, 아래 5px 역할색 띠, 이름과 배지.
- **잠김**: 그림을 검은 실루엣으로, 이름은 `???`.
- **희귀(멸종위기·외래종)**: 금색 테두리. 상세 화면에 빨간 "멸종위기 야생생물" 또는 "생태계 교란 생물" 태그.
- **끄는 중**: −3° 기울기, 남색 테두리, 큰 그림자.

### 6.3 EventCard (사건 카드)
- 검은 3px 테두리 + `6px 6px 0` 각진 그림자, −1° 기울기로 신문 오려 붙인 느낌.
- 머리띠: `📰 숲 속 소식` / 카드 번호.
- 큰 그림(72px) + 변화 도장(`−70%`, 빨간 테두리, 12° 기울기) + 제목 + 2문장 설명 + 영향 칩.
- 발동 연출: 카드가 뒤집히며 등장(0.5초) → 대상 노드 맥박 효과.

### 6.4 PredictionPanel (예측)
- 질문마다 남색 번호 원 + 굵은 질문 + 오른쪽 배점 칩.
- **변화 보기(질문 1)**: 3칸 큰 버튼(높이 64px), ▲늘어요 / ▼줄어요 / ●비슷해요.
- **생물 고르기(질문 2)**: 그림+이름 타일 격자. 사건이 직접 건드린 생물은 비활성.
- **이유 고르기(질문 3)**: 라디오형 긴 버튼. 선택 시 남색 테두리와 채운 점.
- 세 질문을 모두 답해야 "예측 제출" 버튼이 활성화됩니다.

### 6.5 PopulationBars (개체 수 막대)
- 한 줄: 그림 / 이름 / 막대 / 변화 칩. 막대 최대값은 지수 150, 기준 100 위치에 세로 점선.
- 막대 채움은 역할색, 변화 칩은 변화색(▲▼●)으로 역할과 변화를 구분합니다.
- 예측에 나온 생물(질문 1·2 대상) 줄은 금색 바탕으로 강조.
- 턴이 바뀔 때 0.6초 동안 부드럽게 늘고 줄어듭니다.

### 6.6 TurnTimeline · PlaybackControls
- 0~8턴 원형 칸: 지난 턴(옅은 남색) / 현재 턴(남색 + 금색 테두리) / 남은 턴(종이색).
- 버튼: ▶ 재생(⏸ 멈춤으로 바뀜, 1.1초에 1턴) / 한 턴 ⏭ / ↺ 처음.
- 막대 아래 **해설 말풍선**: 턴마다 템플릿 문장(PRD 6.5)으로 무슨 일이 일어났는지 알려 줍니다.

### 6.7 ScoreCard · InfluenceChain (수사 보고서)
- 점수 카드: 맞음(초록 테두리 + ○) / 틀림(빨강 테두리 + ✕), 내 답과 실제 결과, 획득 점수.
- 영향 경로: 생물 카드 → 금색 화살표 → 생물 카드. 각 카드 아래 변화 칩.
- 설명 카드: 그림 + 굵은 결과 문장 + 원인 문장 + (원인 유형).

### 6.8 ActionCard (관리인 행동)
- 큰 그림 + 이름 + 효과 한 줄 + 예산(💰). 선택 시 초록 테두리와 연초록 바탕.
- 지금 쓸 수 없는 행동은 이유를 비용 줄에 적고 흐리게 표시합니다.

### 6.9 TeamBoard (모둠 대항전, 전자칠판)
- 어두운 남색(`#1E2B3D`) 바탕으로 교실 앞 화면에서 눈부심을 줄이고 대비를 높입니다.
- 큰 사건 카드 + 원형 타이머(금색 진행 링).
- 모둠 타일: 이름 + ▲▼● 버튼(높이 48px) + 상태. 입력을 마친 모둠은 금색 테두리.
- **답 가리기** 옵션: 켜면 공개 전까지 선택한 색을 숨기고 "✔ 입력 완료"만 보여 줍니다.
- 점수판: 순위(금색 숫자) + 금색 그라데이션 막대 + 점수.

## 7. 화면별 명세

### 01 메인
- 인사 영역: 탐정 배지(84px 원) + "13번 탐정단원, 오늘의 사건을 해결해 볼까요?"
- 테마 카드 3장: 그라데이션 그림 영역(생물 5종) + 스테이지 태그 + 별 15개 + 진행 막대. 잠긴 테마는 열리는 조건을 태그에 표시.
- 모드 4개: 먹이 그물 만들기 / 사건 수사(관리인 모드) / 자유 실험실 / 카드 도감.

### 02 먹이 그물 만들기
- 위: 진행률(연결한 관계 수), 힌트(별 −1), 층별 정렬, 분해자 연결 보기 토글.
- 왼쪽: 카드 보관함(아직 놓지 않은 카드). 아래에 화살표 규칙 안내.
- 가운데: 캔버스. 아직 놓지 않은 카드는 자리만 흐리게 표시.
- 아래: 피드백 띠. 방향을 거꾸로 그리면 "화살표 방향을 다시 생각해 봐요!"

### 03 사건·예측
- 왼쪽: 사건 카드 + 대상이 깜빡이는 먹이 그물(작게).
- 오른쪽: 예측 패널(질문 3개) + "먹이 그물 크게 보기" + "예측 제출하고 관찰하기".

### 04 시뮬레이션 관찰
- 위: 사건과 내 예측 요약 띠(검정), 턴 타임라인, 재생 버튼.
- 왼쪽: 영향 흐름이 보이는 먹이 그물 + 범례.
- 오른쪽: 개체 수 막대 + 턴별 해설 말풍선.
- 시안에서 ▶ 재생, 한 턴 ⏭, ↺ 처음을 눌러 동작을 확인할 수 있습니다.

### 05 수사 보고서
- 총점 + 별 + 한 줄 칭찬·조언 + 새 카드 보상.
- 질문별 점수 카드 3장 → 영향이 퍼진 길 → 생물별 설명 카드 → 관리인 행동 카드 3장 → "행동하고 4턴 더 지켜보기".

### 06 카드 도감
- 위: 테마 탭(수집 수 포함) + 희귀 카드 탭.
- 왼쪽: 카드 격자. 오른쪽: 선택한 카드 상세(큰 그림, 보호 등급 태그, 사는 곳·먹이·천적, 한 줄 사실, 먹이 그물에서 위치 보기).

### 07 모둠 대항전
- 전자칠판 전체 화면. 사건 카드와 타이머 → 모둠별 예측 입력 → "모두 공개하고 시뮬레이션 보기" → 점수판.

### 08 교사 화면
- 요약 수치 4개(학생 수, 사전→사후 평균, 간접 효과 정답률, 예측 정답률).
- 학생별 표: 번호, 사전→사후 막대, 간접 효과 문항 변화, 서술형 답, 진행 스테이지, 예측 정답률.
- 표 아래 자동 안내: 오개념이 남은 학생과 추천 활동.
- 상단: CSV 내보내기, 카드 전체 열기.

## 8. 그림(일러스트) 방향

- 시안은 이모지로 대신했습니다. 실제 앱에서는 **같은 화풍의 둥근 일러스트**(굵은 외곽선, 단순한 면, 정면 또는 3/4 측면)로 통일합니다.
- 생물은 실제 모습과 특징(색, 무늬)이 틀리지 않게 그립니다. 예: 칠게의 긴 눈자루, 저어새의 주걱 모양 부리.
- 크기: 노드용 64px, 카드용 192px, 상세용 384px(SVG 권장).
- 역할색은 그림에 넣지 않고 테두리·띠로만 표현해, 그림을 바꿔도 체계가 유지되게 합니다.
- 필요한 그림: 생물 약 40종, 사건 카드 약 18장, 관리인 행동 약 6장, 탐정 배지·빈 상태 그림 몇 장.

## 10. 접근성 체크리스트

- [ ] 늘어남·줄어듦은 색 + ▲▼● + 숫자로 함께 표시했는가
- [ ] 역할은 색 + 글자 배지로 함께 표시했는가
- [ ] 터치 영역이 48×48px 이상이고, 카드 사이 간격이 8px 이상인가
- [ ] 본문 글자와 바탕의 명도 대비가 4.5:1 이상인가(1차 소비자 배지는 잉크색 글자 사용)
- [ ] 먹이 그물 SVG에 `role="img"`와 설명(`aria-label`)이 있는가
- [ ] 화면 읽기 프로그램용으로 먹이 관계를 목록(예: "메뚜기 → 개구리")으로도 제공하는가
- [ ] 소리 없이도 모든 피드백을 알 수 있는가
- [ ] 어려운 낱말(생산자, 분해자 등)을 누르면 뜻 풀이가 나오는가

## 11. 구현 지침 (바이브 코딩용)

1. 3장의 토큰을 `src/styles/tokens.css`에 CSS 변수로 그대로 옮깁니다. 컴포넌트에서는 색 값을 직접 쓰지 말고 변수만 씁니다.
2. 먹이 그물은 시안의 `draw()` 함수처럼 **데이터(노드·관계) → SVG** 구조로 만듭니다. 실제 앱에서는 d3-force에 `forceY(영양 단계별 y)`를 더해 층을 유지하고, 시안 좌표는 초기 위치로 씁니다.
3. 화살표 끝은 노드 반지름(34px)+여유 4px만큼 줄여서 그려야 화살촉이 원에 가려지지 않습니다.
4. 개체 수 막대와 변화 칩의 판정(±10%)은 엔진의 채점 함수와 **같은 함수**를 써서 화면과 점수가 어긋나지 않게 합니다.
5. 전자칠판 화면은 별도 레이아웃(`TeamBoard`)으로 만들고, 글자 크기 배율을 변수 하나(`--board-scale`)로 조절합니다.
6. 시안에 없는 화면(시작·번호 입력, 진단, 자유 실험실, 설정)은 01·03 화면의 패널·버튼·보기 컴포넌트를 조합해 만듭니다.
