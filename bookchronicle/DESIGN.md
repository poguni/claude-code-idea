## 1. 콘셉트: 해마다 한 칸씩 늘어나는 책장

나무가 해마다 나이테를 한 겹씩 두르듯, 1년에 책장 한 칸이 늘어납니다. 화면을 여는 순간 "내 책장 앞에 선 느낌"이 들어야 하고, 그 느낌이 **다음 책을 기록하고 싶은 마음**으로 이어지는 것이 목표입니다.

### 디자인 원칙
1. **책이 주인공**: 장식은 줄이고, 책등의 색과 무늬가 화면의 색을 만들게 합니다. 바탕·패널은 책등보다 한 발 물러난 색을 씁니다.
2. **넓게 펼친 서재**: 데스크톱에서는 가운데에 콘텐츠를 몰지 않고, 사이드바·책장·상세 패널로 화면 폭 전체를 씁니다. 남는 폭은 책장이 가져갑니다.
3. **같은 기능, 다른 분위기**: 서재·종이 두 테마는 배치·기능·정보가 완전히 같고, 색·글꼴·선반 재질·장식만 다릅니다.
4. **손에 잡히는 상호작용**: 책은 마우스를 올리면 들리고, 누르면 빠져나와 표지를 보여 줍니다. 실제 책을 꺼내는 동작을 흉내 냅니다.
5. **누구나 읽을 수 있게**: 책등 글자는 명암비를 계산해 색을 고르고, 회전 애니메이션은 '동작 줄이기' 설정을 따릅니다.

| 현재 파일 | 새 저장소 위치 | 내용 |
|---|---|---|

- 두 HTML은 같은 코드이며 `<html data-theme="...">` 기본값만 다릅니다. 어느 파일에서든 사이드바의 **보기 설정**으로 테마와 책등 스타일을 바꿔 볼 수 있습니다.
- **로그인 화면**은 사이드바 아래 계정 영역의 로그아웃 버튼을 누르거나, 주소 끝에 `#login`을 붙여 열면 볼 수 있습니다. 아무 값이나 넣고 로그인을 누르면 책장으로 돌아갑니다.
- 시안의 책 데이터는 화면 확인용 예시입니다. 실제 앱에서는 Supabase에서 불러옵니다.
- 시안은 인터넷 연결 시 Google Fonts를 불러옵니다. 연결이 없으면 시스템 글꼴로 보입니다.
- 시안의 표지는 팔레트로 만든 **간이 표지**입니다. 실제 앱에서는 알라딘 표지 이미지가 들어갑니다.

## 3. 디자인 토큰

모든 색·글꼴·재질은 CSS 사용자 정의 속성으로 정의하고 `[data-theme="study"]`, `[data-theme="paper"]`에서 값만 바꿉니다. 컴포넌트 CSS에는 색상값을 직접 쓰지 않습니다.

| `--side` | 사이드바 | `#17110D` | `#FBF9F4` |
| `--panel` | 상세 패널 | `#241B15` | `#FBF9F4` |
| `--card` | 카드·입력창 | `#2E231B` | `#FFFFFF` |
| `--line` | 구분선·테두리 | `#3A2D22` | `#E6DFD2` |
| `--text` | 본문 글자 | `#F3E9D7` | `#1D2433` |
| `--muted` | 보조 글자 | `#B9A88F` | `#5E6573` |
| `--accent` | 강조(버튼·선택·현재 달) | `#D4A55A` 황동 | `#2F4A7A` 남색 잉크 |

| `--bar` / `--bar-off` | 월별 막대 / 아직 오지 않은 달 | `#8C6B45` / `#3A2D22` | `#9AA6BC` / `#DED6C8` |

### 색 사용 규칙
- 강조색은 화면당 **주요 행동 1개**(책 꽂기 버튼)와 **현재 상태**(선택한 메뉴, 현재 달, 선택한 책 테두리)에만 씁니다.
- 책등 색은 토큰이 아니라 **책 데이터(팔레트)**에서 옵니다. 그래서 책장은 테마와 상관없이 같은 색으로 보입니다.
- 보조 글자 `--muted`는 두 테마 모두 바탕과 명암비 4.5:1 이상입니다(서재 약 7:1, 종이 약 5.6:1).
- 성공 상태(저장됨)는 `#7FB069` 점으로 표시하고 글자로도 함께 알립니다.

### 3.2 치수와 모서리

| 토큰 | 값 | 용도 |
|---|---|---|
| `--side-w` | 232px | 사이드바 폭 |
| `--detail-w` | `clamp(360px, 26vw, 440px)` | 상세 패널 폭 |
| `--radius-s` / `-m` / `-l` | 8 / 12 / 16px | 칩 / 버튼·입력창 / 카드 |
| `--spine-k` | `0.019cqw` | 쪽당 책등 두께(책장 폭 기준 컨테이너 단위) |
| `--spine-hk` | `clamp(0.72px, 0.07vw, 0.98px)` | 책등 높이 배율 |
| `--ease-book` | `cubic-bezier(.2,.7,.2,1)` | 책 꺼내기 움직임 |

- 간격은 4px 배수를 씁니다(주로 8·12·16·24·28px).
- 터치·클릭 대상은 최소 44×44px입니다(책등은 예외: 두께가 데이터이므로 대신 키보드 이동을 지원).

## 5. 레이아웃

### 5.1 앱 셸 (데스크톱 1200px 이상)
```
┌ 사이드바 232 ┬──────────── 책장 (1fr, 남는 폭 전부) ────────────┬ 상세 패널 360~440 ┐
│ 로고          │ 날짜 · 페이지 제목 · 올해 요약        검색 · 정렬    │ 선택한 책          │
│ [책 한 권 꽂기]│                                                    │  표지 · 제목 · 별점 │
│ 메뉴 6개      │ 2026 ─ 책장 ─────────────────────────── 그해의 책  │  쪽수 · 완독 · 분야 │
│ 연도별 나이테 │ 2025 ─ 책장 ───────────────────────────            │  한 줄 메모         │
│  (연도+색 띠) │ 2024 ─ 책장 ───────────────────────────            │ 2026 한눈에         │
│ 보기 설정     │                                                    │  통계 4칸 · 월별    │
│ 계정·저장 상태│                                                    │ 올해의 나이테       │
└──────────────┴────────────────────────────────────────────────────┴────────────────────┘
```
- CSS Grid: `grid-template-columns: 232px minmax(0,1fr) var(--detail-w)`.
- 책장 영역 안쪽 여백: `clamp(20px, 2.8vw, 48px)`.
- 1440×900에서 2026·2025년 책장이 첫 화면에 온전히 보이고, 2024년은 스크롤해서 봅니다.

### 5.2 반응형

| 폭 | 변화 |
|---|---|
| 1200px 이상 | 3단 |
| 900~1199px | 2단. 상세 패널은 오른쪽에서 밀려 나오는 서랍(책을 누르면 열림, 닫기 버튼) |
| 900px 미만 | 1단. 사이드바는 위에 붙는 **상단 바**(로고 + 메뉴 버튼)로 바뀌고, 메뉴·연도·보기 설정·계정은 버튼으로 펼침. 펼친 메뉴는 화면 높이를 넘으면 메뉴 안에서 스크롤. 검색은 한 줄 전체, 정렬 칩은 3등분. 상세 패널은 책장 아래로 내려가고 책을 누르면 그 위치로 스크롤 |

- 책등 두께는 책장 폭에 비례(`cqw`)하므로, 화면 폭이 바뀌어도 한 해 책장이 한 줄 안에 비슷한 비율로 들어갑니다.
- 가로 스크롤이 생기지 않아야 합니다(390px에서 확인).

## 6. 책장과 책등

### 6.1 책장(Shelf)
- 한 연도 = 머리글(연도, 권수·쪽수, 오른쪽 끝에 그해의 책) + 책장 + 선반 판.
- 책장 높이: `calc(176 × --spine-hk + 22px)`. 책은 아래쪽에 정렬하고 사이 간격 2px.
- 서재: 뒤판(`--shelf-back`) 위에 안쪽 그림자로 깊이감. 종이: 뒤판 없이 벽에 단 선반, 판 아래 그림자만.
- 책장에는 `perspective: 1400px`를 주어 꺼낸 책이 입체로 보이게 합니다.

### 6.2 책(Book) 구조
책 한 권은 CSS 3D 상자입니다.
```
<button class="book" aria-pressed>      ← 위치·크기·움직임
  <span class="face spine pat-…">       ← 책등 면(정면)
    <span class="tex"></span>           ← 표지 질감 모드용 흐림 그림
    <span class="ov"></span>            ← 표지 질감 모드용 바탕색 덧칠
    <span class="t">제목</span>
    <span class="a">저자</span> | <span class="mk"></span>
  </span>
  <span class="face cover">표지</span>  ← 오른쪽 옆면(평소엔 안쪽으로 90° 접혀 있음)
  <span class="ribbon"></span>          ← 그해의 책일 때만
</button>
```
- 두께: `clamp(8px, 쪽수 × --spine-k, 9cqw)`
- 높이: `(132 + 고정 난수 0~41) × --spine-hk`
- 표지 면 폭: 책 높이 × 0.68
- 책등 공통 질감: 아주 옅은 노이즈(SVG feTurbulence, 22%, overlay) + 왼쪽 밝은 선·오른쪽 어두운 그림자로 둥근 책등 표현

### 6.3 생성형 책등 패턴 (기본)
책 데이터의 팔레트 3색 `--base`(바탕) · `--band`(띠) · `--accent-c`(강조)로 칠합니다.

| 패턴 | 그리는 법 | 기본 분야 |
|---|---|---|
| **하드커버** | 바탕색 + 위쪽 8px·13px, 아래쪽 8px·13px 위치에 강조색 띠(2px, 1px). 제목은 위에서 22px부터, 아래쪽 20px에 7px 사각 표시(출판사 자리) | 인문·역사·과학·사회·경제경영 |
| **페이퍼백** | 위쪽 18%를 띠색 블록으로, 나머지는 바탕색. 아래쪽 7px 위치에 강조색 3px 줄. 저자를 아래쪽에 작게 | 소설/시/희곡 |
| **라벨형** | 바탕색 위 제목 뒤에 띠색 라벨 상자(위아래 6px 여백, 모서리 2px). 저자를 아래쪽에 작게 | 에세이·예술·기타 |

- 글자색: 글자가 놓이는 면(바탕 또는 라벨)의 상대 휘도가 0.36보다 크면 `#1F1A16`, 아니면 `#FBF7EF`.
- 제목은 240쪽 미만(아주 얇은 책)이면 숨기고, 상세 패널에서만 보여 줍니다.

### 6.4 표지 질감 모드 (설정)
- `<html data-spine="texture">`일 때 적용합니다.
- `.tex`: 표지 이미지를 가로 500%·세로 130%로 늘려 책마다 다른 위치(`--tx`)를 보여 주고 `blur(5px) saturate(1.25)`.
- `.ov`: 바탕색을 42% 덧칠해 제목 가독성을 확보합니다.
- 패턴의 띠·사각 표시는 숨기고, 제목에 옅은 그림자(`0 1px 2px rgba(0,0,0,.35)`)를 줍니다.
- 실제 앱에서는 흐림 그림을 등록 시 64×256px 이미지로 미리 만들어 둡니다(PRD 6.5).

### 6.5 그해의 책 표시
- 책등 아래로 늘어진 책갈피 끈: 폭 6px, 길이 28px, 끝이 V자(`clip-path`), 색 `--ribbon`.
- 연도 머리글 오른쪽에 책갈피 아이콘 + "그해의 책 · 제목".

## 7. 컴포넌트 명세

### 7.1 사이드바
- **브랜드**: 나이테 아이콘(동심원 4개, 강조색 선 1.4px) + "북크로니클"(display 21px) + "BOOK CHRONICLE"(11px, 자간 0.18em).
- **책 한 권 꽂기**: 주 버튼, 높이 48px, 강조색 바탕.
- **메뉴**: 책장 · 연도 비교 · 연말 회고 · 전체 목록 · 가져오기·백업 · 설정. 높이 44px, 현재 메뉴는 카드색 바탕 + 굵게 + 아이콘 강조색.
- **연도별 나이테**: 연도(display 16px) + 권수 + 그해 책등 색을 쪽수 비율로 이어 붙인 8px 띠. 누르면 그 연도 책장으로 이동. 현재 보는 연도는 강조색 테두리.
- **보기 설정**: 2칸 세그먼트 컨트롤 두 개(테마: 서재/종이, 책등: 생성형 책등/표지 질감).
- **계정 영역**(바닥): 카드 안에 이니셜 원(32px, 강조색) + "내 계정" + 저장 상태(점 + "저장됨 · 백업 12일 전") + 로그아웃 아이콘 버튼(44px). 이메일 주소 전체는 화면에 늘 띄우지 않고 설정 화면에서만 보여 줍니다.
- **출처**: 계정 영역 아래 "도서 DB 제공: 알라딘 인터넷서점"(12px, 보조색).

### 7.2 상단
- 날짜 줄(13px, 보조색) → 페이지 제목(display) → 올해 요약(권수·쪽수·평균 별점은 display 18px 숫자, "작년보다 +3권"은 강조색 굵게).
- 오른쪽: 검색창(높이 46px, 카드색) + 정렬 칩 3개(완독일순/색상순/분야순, 선택 칩은 강조색 테두리).

### 7.3 상세 패널
- **선택한 책**: 큰 표지(120×174px, 왼쪽 안쪽 그림자로 제본선) + 그해의 책 태그 + 제목(display 22px) + 저자 + 별점(반 별 지원).
- **사실 3칸**: 쪽수 · 완독(`2026.10`) · 분야. 카드 안 라벨 11px, 값 굵게.
- **한 줄 메모**: 공책 줄 배경(32px 간격, 선 색 `--line`), display 글꼴 16px. 메모가 없으면 "아직 남긴 한 줄이 없어요…" 안내.
- **버튼**: 기록 수정(보조) · 그해의 책으로(강조 테두리).
- **2026 한눈에**: 2×2 통계 카드 + 월별 막대(12칸, 현재 달 강조색, 아직 오지 않은 달은 `--bar-off`).
- **올해의 나이테**: 132px 동심원. 바깥 고리가 올해, 고리 두께는 권수에 비례, 고리 조각 하나가 책 한 권(색 = 책등 바탕색). 고리 사이 4px 틈. 옆에 한 줄 설명과 "회고 카드 만들기".

### 7.4 로그인 화면
- 화면 전체를 테마 바탕색으로 덮고, 가운데에 카드(폭 최대 420px, 안쪽 여백 36px 32px, 모서리 20px, `--panel` 바탕)를 둡니다.
- 카드 위쪽에 **작은 책장 그림**(책등 8권 + 선반 판 6px)을 두어 앱의 첫인상을 이어 갑니다.
- 라벨 "북크로니클 · BOOK CHRONICLE" → 제목 "책장으로 돌아오신 걸 환영해요"(display 26px) → 보조 문구 "기존 독서 앱과 같은 계정으로 로그인합니다."
- 입력: 이메일·비밀번호(높이 48px, `<label>`로 연결, `autocomplete` 지정). 주 버튼 "로그인"(높이 48px).
- 회원 가입 링크는 두지 않습니다. 실패 시 입력창 아래에 "이메일 또는 비밀번호를 확인해 주세요"(강조색이 아닌 본문색 + 경고 아이콘).
- 로그인 방식이 소셜 로그인으로 정해지면 입력창 대신 제공자 버튼 1개로 바꿉니다(기존 앱 분석 후 확정).

### 7.5 버튼과 칩
| 종류 | 모양 |
|---|---|
| 주 버튼 | 높이 48px, 모서리 12px, 강조색 바탕, 글자 `--accent-ink` 굵게 |
| 보조 버튼 | 높이 44px, 카드색 바탕, `--line` 테두리 |
| 강조 테두리 버튼 | 높이 44px, 투명 바탕, 강조색 테두리·글자 |
| 칩(정렬 등) | 높이 46px(모바일 40px), 선택 시 강조색 테두리 + 굵게, `aria-pressed` |
| 세그먼트 컨트롤 | 2칸, 선택 칸 강조색 바탕, `role="radio"` + `aria-checked` |

## 9. 접근성
- 책은 `<button>`이며 `aria-label`에 "제목, 저자, 쪽수, 완독 연월, (그해의 책)"을 담습니다. 선택 상태는 `aria-pressed`.
- 아이콘만 있는 버튼(메뉴 열기, 상세 닫기)에는 `aria-label`.
- 월별 막대, 나이테는 `role="img"` + 설명 라벨. 실제 앱에서는 "표로 보기"를 함께 제공합니다.
- 검색창에는 화면에 보이지 않는 `<label>` 텍스트.
- 포커스 링: 강조색 2px, 간격 2px.
